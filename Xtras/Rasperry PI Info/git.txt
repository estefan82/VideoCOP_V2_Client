🔹 1. Crear nuevas funcionalidades

Cada cosa nueva → su propia rama

git checkout dev
git checkout -b feature/nombre-funcion

🔹 2. Trabajas normalmente

Editas código, pruebas, etc.

git add .
git commit -m "Añadido X funcionalidad"
git push origin feature/nombre-funcion

🔹 3. Cuando funciona → lo pasas a dev
git checkout dev
git pull origin dev
git merge feature/nombre-funcion
git push origin dev

🔹 4. Cuando está estable → a main
git checkout main
git pull origin main
git merge dev
git push origin main

🔹 5. Limpieza (opcional pero pro)
git branch -d feature/nombre-funcion
git push origin --delete feature/nombre-funcion

🔹 6. Cambiar de rama
git checkout nombre-rama

🔹 7. Crear rama
git checkout -b (nombre_rama)
